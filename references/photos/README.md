# Затверджені еталони

2026-09-17 користувач надав і схвалив глобальний стиль товарної інфографіки:
`global/commercial-infographic-approved-2026-09-17.png`.
Він додатково уточнив: кожен товар має окрему концепцію, а всі п'ять фото товару
мають бути різними за сценою, композицією, смислом і розміщенням інфографіки.

Схвалено стиль і рівень оформлення. Цифри, бренди, вигляд та характеристики товарів
зі зразка не є даними для інших SKU. Джерело товарної ідентичності — точні фото UG-OPT.

Наступні схвалені файли зберігай у підкаталозі категорії/товару і реєструй
у config/photo-styles.json. Профіль має instructions і references з path/reason.
Шлях починається з references/photos/. reason описує область схвалення.
Відсутній файл блокує план; хеш еталону рахується з фактичних байтів.
